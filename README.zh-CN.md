# Base_ML_Notebooks · 机器学习基础笔记本

[English](README.md) | 简体中文

本仓库收录了一组**机器学习基础 Notebook**，可作为各类项目的起点和积木。它们演示了常见的机器学习技术与工作流程，便于直接复用，或根据具体需求进行改造。

## 内容

| 文件 | 说明 |
| --- | --- |
| `Pandas_profiling.ipynb` | 使用 pandas-profiling 对数据集进行快速探索性分析（EDA），自动生成数据概况报告 |
| `Sentiment_analysis_twitter_using_algorithms.ipynb` | 基于传统机器学习算法的 Twitter 情感分析 |
| `Twitter_Sentiment_Analysis_using_neural_network.ipynb` | 基于神经网络的 Twitter 情感分析 |
| `b_SentimentAnalysis_with_NeuralNetwork.ipynb` | 神经网络情感分析的另一种实现 |

## 使用方法

1. 克隆仓库后，用 Jupyter Notebook / JupyterLab 打开任意 `.ipynb` 文件，或直接上传到 Google Colab 运行。
2. 按照 Notebook 中的单元格顺序依次执行即可。
3. 可以把其中的数据预处理、建模和评估步骤复制到自己的项目中，作为模板使用。
